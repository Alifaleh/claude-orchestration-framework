# Home

Second brain for all projects and personal context. Written and maintained by Claude sessions
(main sessions only — subagents never write here) and by me.

## Map

| Folder | Holds | Auto-write? |
|---|---|---|
| `00 - Brain` | Who I am: [[About Me]], Contacts/ (one note per person) | Proactive capture of durable personal facts; never secrets |
| `01 - Projects` | One note per workspace — the cross-project memory core | Yes — decisions and the WHY, durable summaries |
| `02 - Work` | Bank / work context | Proactive capture of durable work facts |
| `03 - Knowledge` | Technical knowledge worth keeping across projects | Yes |
| `04 - Journal` | Manual journaling | No — manual use only |
| `05 - Templates` | Note templates (Project Note, Contact) | — |

## Conventions

- `[[wikilinks]]` between notes; YAML frontmatter on every note.
- End every created/updated note with `*Last updated: YYYY-MM-DD*`.
- Durable summaries, not session play-by-play. Update the existing note rather than spawning a new one.
- Never delete or overwrite vault content without asking me first.
- The vault is a git repo: commit and push after every write.
